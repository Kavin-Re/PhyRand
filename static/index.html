Decrypt a file

You need the encrypted file, its file ID and its release token. The key is fetched from the server; decryption happens in this browser and the file is not uploaded.

Encrypt a file

The server generates a key from health-tested noise-source bytes mixed with its OS random generator, and keeps a copy (key escrow). The file is encrypted here with Fernet and never leaves this browser.
